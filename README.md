# 112 寝 · 2栋3号房 — H5 2D 漫游小游戏

根据一张寝室实拍照片做的 **Low-poly Stylized 2D 漫游游戏**：玩家扮演刚刚洗漱回来的自己，
在**寝室、阳台、走廊**三个场景里走动，开关门进出不同空间，和四位舍友聊几句，
最后关灯睡觉，结束「第一夜」。

> 场景、家具、人物、灯光、音效全部由代码程序化生成（Canvas 2D 绘制贴图 + Phaser 矢量小人 +
> WebAudio 现场合成音效），仓库里没有任何图片 / 音频资源文件。

## 快速开始

```bash
npm install
npm run dev        # 开发： http://localhost:5173
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览构建结果
```

## 玩法

- **三个场景**：寝室（主场景）、阳台（晾衣服、看夜景）、走廊（一排宿舍门 / 楼梯口 / 饮水机）
- **开门转场**：北门通往走廊、南侧推拉门通往阳台，门有开合动画 + 开门音效
- **四位舍友**：阿哲（熬夜肝毕设）、小胖（边吃边学）、老K（床神，躺下铺）、阿伟（阳台常驻）
  - 每人 4 句主对话 + 3 个可选分支，聊过一次后会换成一句短对话
- **任务**：右上角「今晚的搭话 0/4」；四位都聊过之后，墙上的灯开关才可用
- **结局**：按下开关 → 全寝熄灯 → 「第一夜 · 完」结算画面 → 可「再玩一次」
- **可交互杂物**：蓝色保温瓶、黄色快递袋、纸箱堆、垃圾袋、蚊帐、窗外、风扇开关、
  洗衣机、公告栏、饮水机、楼梯口、邻居的门……都有旁白

## 技术栈

- **Phaser 3**（WebGL 渲染，Arcade 物理）
- **TypeScript**（strict）
- **Vite** 构建 / 开发服务器
- 纯前端，无后端；`dist/` 可直接扔到任意静态托管上（H5，自适应手机 / 桌面）

## 美术实现说明

- **伪 3/4 视角**：地板是俯视，家具按「顶面 + 朝南的正面」拼；每个物件单独一张贴图、单独一个
  `depth = 底边 y`，所以人物走到床后 / 桌前时遮挡关系是对的。
- **贴图管线**：`core/canvas.ts` 里 `define(key, w, h, draw)` 注册，启动时按 2 倍超采样烘焙成
  Canvas 贴图（镜头 zoom = 2.25，正好接近 1:1 显示）。
- **剖切墙**：相机宽度恰好等于一屏宽，两侧不是黑边，而是被"切开"的混凝土断面 + 室内墙面。
- **灯光**：地面光斑（ADD 混合、缓慢呼吸）、吊扇投在地上的旋转影子、屏幕暗角与暖色叠加。
- **小人**：由多边形块面拼成的容器，靠 transform 做走路 / 呼吸 / 打字 / 躺床动作；四个朝向分别
  处理脸、后脑和侧面鼻子。
